# 星耀 X9 Pro 智能手机 商品说明

## 产品概述
星耀 X9 Pro 是星耀科技 2026 年旗舰智能手机,主打影像与续航,搭载第二代骁龙 8 至尊版处理器,配备 6.7 英寸 2K 曲面屏,支持 IP68 级防尘防水。

## 核心参数
- 处理器: 第二代骁龙 8 至尊版
- 内存: 12GB / 16GB LPDDR5X
- 存储: 256GB / 512GB UFS 4.0
- 电池: 5500mAh,支持 120W 有线快充与 50W 无线快充
- 摄像头: 后置 5000 万像素主摄 + 5000 万超广角 + 6400 万潜望长焦
- 重量: 198g
- 系统: 星耀 OS 5.0(基于 Android 15)

## 使用说明
### 首次开机
长按电源键 3 秒开机,按照屏幕提示选择语言、连接 Wi-Fi 并登录星耀账号。

### 快充注意事项
请使用包装内原装 120W 充电器与数据线,第三方充电器可能无法触发满功率快充。充电时建议移除厚重保护壳以利于散热。
